# 🌍 World Population vs Internet Users

A beginner-friendly Python data analysis project using **Pandas** and **Matplotlib** to explore the growth of internet users compared with the world's population.

---

## 📌 About the Project

This project combines two datasets:

- 🌍 World population data
- 🌐 Global internet users data

The datasets are merged using the `year` column.

After combining the data, the percentage of the world's population using the internet is calculated.

The final result is visualized using **Matplotlib**.

---

## 🛠️ Technologies Used

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
- 📄 CSV
